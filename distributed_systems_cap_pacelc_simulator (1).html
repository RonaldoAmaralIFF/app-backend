Guia Teórico para Exploração e Aula Prática

Como mapear este simulador com os conceitos apresentados nos slides.

1 Compreendendo o Trilema CAP

No cenário **Saudável (Healthy)**, o sistema garante tanto Consistência quanto Disponibilidade de forma síncrona ou assíncrona.

Quando você ativa a **Partição de Rede (Partition)**, o Nó Gamma fica isolado. Se você tentar realizar uma escrita com consistência **ALL** ou **QUORUM** no Nó Gamma isolado, a operação falhará por falta de consenso (o nó não consegue alcançar o quorum de 2). Isso demonstra o comportamento **CP (Consistency / Partition-tolerant)**.

Se o sistema estiver configurado para consistência de escrita **ONE**, a escrita no Nó Gamma terá sucesso imediato, mas os dados não se propagarão aos outros nós. Ao realizar a leitura no Nó Alpha com consistência **ONE**, o usuário lerá o dado antigo. Isso demonstra o comportamento **AP (Availability / Partition-tolerant)**.

2 Mapeando o Teorema PACELC

O Teorema PACELC expande a análise para o tempo de paz: se **não** houver partição (**E**lse), qual é o trade-off entre Latência (**L**) e Consistência (**C**)?

Ao selecionar a estratégia de **Replicação Síncrona**, toda escrita deve esperar a confirmação de todos os nós para retornar sucesso ao cliente. No gráfico de performance, observe o aumento expressivo na latência de escrita. No entanto, a consistência é mantida em 100%.

Ao alternar para a **Replicação Assíncrona**, a resposta é instantânea ao cliente. A latência cai para quase zero, mas se houver leitura concorrente imediata, o dado poderá retornar inconsistente até que a replicação de background termine (consistência eventual).
